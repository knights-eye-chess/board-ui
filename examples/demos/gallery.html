Make it yours.

Switch between bundled defaults and a custom collection. Themes, pieces, icon artwork and arrow geometry are independent—mix them however you like.

Select squares and browse the icon samples. This is a presentation gallery; the labels are artwork examples, not engine assessments.

Appearance

The custom icon set also adds Saved idea, a host-defined bookmark icon shown on e4. Coordinates stay accessible when printed labels are hidden.

See the integration

Register once at build time

const appearance = createBoardAppearance({
  pieceSets: {
    'outlined-silhouette': { pieces: customPieces }
  },
  iconSets: {
    'diamond-marks': { icons: customIcons }
  },
  squareThemes: { midnight, mint, 'warm-sand': sand },
  arrowStyles: {
    'arrow-chevron-head': chevronArrow
  },
  assetUrls // URLs emitted by your build
});

Change selection at runtime

The catalog is assembled in source before mounting. Runtime controls select registered names; they do not register assets or modify the component’s DOM.
