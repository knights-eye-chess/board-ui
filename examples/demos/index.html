One strip · all three boards

Drag or click to move. Use ↑ / ↓ to switch branches while a board or strip move is focused. Use ← / →, Home and End to navigate a board; on the strip, ← / → selects a move and Enter opens it. Play a different move from an earlier position to add a variation.

See the integration

The headless host uses Lichess chessops for legality and its actual PGN variation tree. Views receive state through board-ui APIs and emit intentions. The host never queries component internals.

One reducer, three viewers

onMove(intent) {
  if (!game.play(intent.uci)) return;
  viewers.forEach((view, index) => {
    view.updateBoard(game.board(
      orientations[index],
      index === source ? intent.intentId : undefined
    ));
  });
  sharedStrip.update(game.strip());
}
